01 · Análisis del caso

Concepción alternativa del estudiante

La idea equivocada

El estudiante puede concluir que “si una función tiene dos fórmulas, el límite no existe”.

El problema es confundir el cambio de expresión algebraica con una ruptura obligatoria del comportamiento de la función.

El criterio correcto

  • Observar qué ocurre cerca del punto.
  • Comparar los límites por izquierda y derecha.
  • Si coinciden, puede existir límite bilateral.
  • Para continuidad, el límite debe coincidir con f(a).
02 · Contextualización pedagógica

La rampa escolar como modelo de continuidad

Situación

La rampa está formada por dos tramos lineales con inclinaciones diferentes.

El punto x = 4 m representa el lugar donde ambos tramos se encuentran.

ModelizaciónContexto realFunciones por tramos

Pregunta generadora

Si una rampa usa dos fórmulas distintas, ¿eso significa que necesariamente existe una ruptura en el punto de unión?

El límite se interpreta como una condición de empalme de alturas.

03 · Modelo matemático

Dos expresiones, un mismo punto de análisis

f(x) = 0.5x, si x < 4     |     f(x) = -0.25x + k, si x ≥ 4
k = 3 · Empalme continuoLímite existe
k = 4 · Aparece un saltoNo existe límite bilateral
04 · Reto algebraico

¿Qué valor de k permite un empalme continuo?

Desde la izquierda

0.5(4) = 2

El primer tramo llega a la altura 2.

Desde la derecha

-0.25(4) + k = -1 + k

Para igualar las alturas:

2 = -1 + k   ⇒   k = 3
k = 3 hace que los dos tramos se aproximen al mismo valor en x = 4.

06 · Objetivo de aprendizaje

¿Qué debe lograr el estudiante?

Objetivo

Distinguir entre cambio de expresión algebraica, existencia del límite y continuidad, mediante límites laterales y un modelo de rampa escolar explorado con GeoGebra.

Resultados esperados

  • Comparar ambos lados.
  • Explicar el límite bilateral.
  • Determinar k = 3.
  • Validar con GeoGebra.
  • Argumentar verbalmente.
07 · Recurso interactivo

GeoGebra: explorar, comparar y validar

Elementos del applet

  • k: modifica la altura del segundo tramo.
  • h: controla la cercanía a x = 4.
  • P y Q: aproximaciones por izquierda y derecha.
  • LI y LD: permiten comparar valores laterales.

Sentido didáctico

El estudiante formula una predicción, manipula el recurso, registra datos y finalmente justifica.

GeoGebra no sustituye la explicación matemática: sirve para contrastarla.

12 · Ticket de salida

Tres preguntas para verificar comprensión

1. Aunque una función use dos expresiones diferentes, el límite bilateral en x = a puede existir si…
2. En el modelo de la rampa, ¿por qué k = 3 produce un empalme continuo en x = 4?
3. Explica una diferencia entre observar f(4) y analizar el límite cuando x se aproxima a 4.

14 · Reflexión docente

De la intuición visual al criterio matemático

La pregunta clave no es “¿cuántas fórmulas tiene la función?”, sino “¿a qué valor se aproxima cada tramo?”.

Argumentación

La gráfica, la tabla de aproximaciones y la condición algebraica fortalecen la comprensión.

Tecnología con propósito

GeoGebra permite predecir, variar parámetros, contrastar y validar resultados.

Conclusión
Dos expresiones algebraicas diferentes pueden compartir el mismo límite.
En el modelo de la rampa, k = 3 garantiza el empalme continuo en x = 4.
