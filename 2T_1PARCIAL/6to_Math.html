T2

Potenciación y radicación con números enteros

Comprendemos qué significa una potencia y cómo encontrar una raíz.

Potenciación

Una potencia es una multiplicación repetida. En (−3)⁴, el −3 es la base y el 4 indica que la base se multiplica cuatro veces.

🔎 (−3)⁴ = (−3) × (−3) × (−3) × (−3) = 81
🔎 (−3)³ = (−3) × (−3) × (−3) = −27
☁ BASE NEGATIVA: exponente par → resultado positivo.   Exponente impar → resultado negativo.

Radicación

La raíz busca el número que, multiplicado por sí mismo las veces que indica el índice, produce el número que está dentro del radical.

🔎 √81 = 9, porque 9 × 9 = 81.
🔎 ∛(−125) = −5, porque (−5) × (−5) × (−5) = −125.
📌 En los números reales no existe la raíz de índice par de un número negativo, por ejemplo √−9.

☁ IMPORTANTE: multiplicación y división tienen la misma prioridad: se resuelven de izquierda a derecha. Lo mismo ocurre con suma y resta.
🔎 Ejemplo resuelto:

−2 { −(−9 + 8) + [15 ÷ √9 + (−4)²] − (−7) }
= −2 { −(−1) + [15 ÷ 3 + 16] − (−7) }
= −2 { 1 + [5 + 16] + 7 }
= −2 { 1 + 21 + 7 }
= −2 { 29 }
= −58

En cada línea se resuelve únicamente lo que corresponde según PEMDAS; lo demás se conserva hasta que llegue su turno.

Proposición condicional y bicondicional

Reconocemos cuándo una proposición compuesta es verdadera o falsa.

Condicional: p → q

Se lee “si p, entonces q”. Solo es falsa cuando p es verdadera y q es falsa.

pqp → q
VVV
VFF
FVV
FFV
🔎 p: “4 es par” = V.   q: “4 es mayor que 10” = F.
Entonces p → q = F.

Bicondicional: p ↔ q

Se lee “p si y solo si q”. Es verdadera cuando p y q tienen el mismo valor de verdad.

pqp ↔ q

FVF
FFV
☁ PARA RECORDAR: Condicional → solo V–F da falso.   |   Bicondicional → valores iguales dan verdadero.

Tablas de frecuencias

Organizamos datos no agrupados y agrupados.

Datos no agrupados

Se usan cuando hay pocos valores diferentes. fi indica cuántas veces aparece cada dato; hi indica qué parte del total representa.

Contar cada dato → fi
→
hi = fi ÷ total
→
% = hi × 100

Datos agrupados

Cuando existen muchos datos, podemos juntarlos en grupos llamados intervalos. Por ejemplo, 10–12 significa: contar todos los datos desde 10 hasta 12, incluyendo ambos extremos.

🔎 Datos: 10, 11, 12, 12, 13, 14, 14, 15, 16, 16, 17, 18
Intervalo Datos que contiene Frecuencia (fi)
10–12 10, 11, 12, 12 4
13–15 13, 14, 14, 15 4
16–18 16, 16, 17, 18 4
Total 12 datos 12
☁ ¿QUÉ SIGNIFICA fi = 4? Que dentro de ese intervalo encontramos 4 datos. La frecuencia no es el valor del intervalo: es la cantidad de datos que contiene.
T6

Medidas de tendencia central

Encontramos media, mediana y moda.

Datos no agrupados

Medida¿Cómo se obtiene?
MediaSe suman todos los datos y se divide para la cantidad de datos.
MedianaSe ordenan los datos y se toma el valor central. Si quedan dos centrales, se suman y se divide para 2.
ModaEs el dato que más veces se repite.
🔎 Datos ordenados: 4, 6, 6, 8, 11
Media = (4 + 6 + 6 + 8 + 11) ÷ 5 = 35 ÷ 5 = 7
Mediana = 6 (está en el centro)
Moda = 6 (es el que más se repite)

Media con datos agrupados

Como no trabajamos con cada dato por separado, usamos el punto medio de cada intervalo, llamado marca de clase (xi).

xi = (límite inferior + superior) ÷ 2
→
fi × xi
→
Σ(fi × xi) ÷ Σfi
🔎 Datos: 10, 11, 12, 13, 13, 14, 14, 15, 16, 18

Antes de calcular la media, contamos cuántos datos pertenecen a cada intervalo:
10–12: 10, 11, 12 → fi = 3
13–15: 13, 13, 14, 14, 15 → fi = 5
16–18: 16, 18 → fi = 2
Intervalo fi xi fi × xi
10–12 3 (10+12)÷2 = 11 3×11 = 33
13–15 5 (13+15)÷2 = 14 5×14 = 70
16–18 2 (16+18)÷2 = 17 2×17 = 34
Total 10 — 137
🔎 Sumamos los productos: 33 + 70 + 34 = 137.
Sumamos las frecuencias: 3 + 5 + 2 = 10.
Media = 137 ÷ 10 = 13,7.
📌 La clase modal es el intervalo con mayor frecuencia. En el ejemplo es 13–15, porque tiene fi = 5.
