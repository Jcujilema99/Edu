Reconocer conexiones esenciales y aplicar un diagnóstico básico, ordenado y seguro.
L1

Tipos de conectores

Reconocemos los conectores que realmente se usan con frecuencia.

Idea principal

Un conector une el computador con otro dispositivo. Lo importante no es memorizar muchos nombres, sino saber qué transmite cada uno y qué dispositivo suele utilizarlo.

ConectorFunción principalEjemplo de uso
USB-A / USB-CDatos y, según el dispositivo, energía.Teclado, memoria USB, teléfono o disco externo.
HDMIAudio y video digital.Conectar monitor, televisor o proyector.
RJ45 / EthernetConexión de red por cable.Computador conectado al router.
Audio 3,5 mmEntrada o salida de sonido.Audífonos, parlantes o micrófono.
📌 Regla útil: nunca fuerces un conector. Si no entra con suavidad, revisa la orientación o confirma que sea el puerto correcto.
🔎 Caso: si quieres mostrar la pantalla del computador en un televisor y también escuchar el sonido, HDMI suele ser la opción adecuada porque transporta video y audio por el mismo cable.
L2

Problemas de hardware

Aprendemos a observar síntomas antes de pensar en una pieza dañada.

Idea principal

El hardware es la parte física del computador. Una falla de hardware puede estar relacionada con alimentación, cables, temperatura o un componente defectuoso. El diagnóstico comienza por lo más simple.

SíntomaPrimera sospechaComprobación segura
No enciendeAlimentación eléctrica.Revisar enchufe, cable, cargador y toma de corriente.
Enciende, pero no hay imagenMonitor o conexión de video.Verificar monitor, entrada seleccionada y cable HDMI/DP.
Se apaga soloTemperatura o alimentación.Observar ventilación, polvo y funcionamiento de ventiladores.
USB no respondePuerto, cable o dispositivo.Probar otro puerto o un dispositivo que sepas que funciona.
🔎 Caso: el computador enciende y el monitor dice “Sin señal”. Antes de abrir el equipo, revisa el cable, la entrada del monitor y el puerto utilizado. Una conexión incorrecta puede parecer una falla grave.
⚠ Seguridad: apaga y desconecta el equipo antes de manipular componentes internos. No abras una fuente de poder; puede conservar carga eléctrica peligrosa.
☁ IDEA CLAVE: diagnosticar es comprobar una hipótesis. Cambiar varias cosas al mismo tiempo impide saber qué causó o solucionó el problema.

Problemas de software

Distinguimos errores de programas y aplicamos soluciones básicas.

Idea principal

El software incluye el sistema operativo y las aplicaciones. Cuando un programa se congela, no abre o aparece un error, conviene resolver el problema de forma gradual: primero acciones simples, luego opciones más profundas.

Programa no abreSi quedó bloqueado o muestra un mensaje.Reiniciar y comprobar actualizaciones.
Equipo lentoAplicaciones abiertas y espacio disponible.Cerrar lo innecesario y reiniciar.
Sin InternetWi‑Fi/cable y estado del router.Reconectar y usar el diagnóstico de red.
Aviso sospechosoOrigen del mensaje.No abrir enlaces y ejecutar un análisis de seguridad.
📌 Diferencia rápida: si una pieza física está rota, es hardware. Si la pieza funciona pero el sistema o una aplicación falla, probablemente es software.
🔎 Caso: un teclado funciona en otros programas, pero no escribe dentro de una aplicación específica. Eso orienta primero a un problema de software, no a reemplazar el teclado.
