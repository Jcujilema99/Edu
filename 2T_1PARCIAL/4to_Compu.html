UNIDAD 2: TRABAJAR CON VENTANAS

Materia para copiar en el cuaderno

L1

El Explorador de archivos

Conocemos la herramienta que permite organizar nuestros documentos.

¿Qué es el Explorador de archivos?

El Explorador de archivos es una herramienta de Windows que sirve para ver, abrir y organizar archivos y carpetas. Con él podemos encontrar tareas, imágenes, documentos y otros trabajos guardados en la computadora.

📄 Archivo: guarda información, por ejemplo una imagen o un documento.
📁 Carpeta: sirve para ordenar y guardar archivos.

🖼️ Así se ve una ventana del Explorador de archivos

Observa que las carpetas y archivos aparecen dentro del área de contenido.
L2

Elementos del Explorador de archivos

Identificamos las principales partes de la ventana.

Partes principales del Explorador

Para usar correctamente esta herramienta debemos reconocer sus partes más importantes.

  • Barra de direcciones: indica en qué carpeta estamos.
  • Panel de navegación: permite entrar rápidamente a otras ubicaciones.
  • Área de contenido: muestra los archivos y carpetas.
  • Cuadro de búsqueda: ayuda a encontrar información.

🧩 Partes de la ventana

L3

Seleccionar archivos y carpetas

Aprendemos a elegir uno o varios elementos.

Seleccionar archivos y carpetas

Seleccionar significa marcar un elemento antes de realizar una acción. El archivo o carpeta seleccionado aparece resaltado.

  • Un archivo: un clic.
  • Varios archivos separados: mantener Ctrl y hacer clic.
  • Todos los archivos: Ctrl + A.

🖱️ Ejemplo de selección

L4

Copiar y mover archivos y carpetas

Organizamos información sin perder nuestros archivos.

Copiar y mover

Copiar crea una segunda versión del archivo y el original permanece en su lugar. Mover cambia el archivo de ubicación.

📋 Copiar: Ctrl + C y luego Ctrl + V.
✂️ Mover: Ctrl + X y luego Ctrl + V.

🔄 Diferencia entre copiar y mover

L5

Crear carpetas y eliminar archivos y carpetas

Mantenemos nuestra computadora organizada.

Crear y eliminar carpetas

Para crear una carpeta podemos hacer clic derecho en un espacio vacío y elegir Nuevo → Carpeta. Después escribimos un nombre claro.

Para eliminar un archivo o carpeta, primero lo seleccionamos y usamos la opción Eliminar. Normalmente pasa a la Papelera de reciclaje.

📁 Organizar bien facilita encontrar tus trabajos

L6

Búsquedas de archivos y carpetas

Encontramos rápidamente lo que necesitamos.

Buscar archivos y carpetas

El cuadro de búsqueda sirve para encontrar rápidamente un archivo o carpeta. Podemos escribir el nombre completo o solo una parte.

🔎 Si el archivo se llama “Tarea_Matemática.docx”, podemos escribir “Tarea” o “Matemática”.
